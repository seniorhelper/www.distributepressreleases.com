The field that matters most

      
mainEntityOfPage declares which URL is the original. When the same release appears on your site, our site and a publisher who took the feed, that field is what stops the copies competing with each other.

      
Get it wrong and a reprint on a stronger domain can outrank the page you control. It is one line, and it is the most common technical failure in syndicated publishing.

      

        
Before you publish: structured data must match what is visible on the page. Markup describing a headline, date or author the page does not actually show is a structured data violation, and it can cost you every rich result you have. Check it with Google's Rich Results Test first.

Schema questions

      

      

        What schema should a press release use?
        
NewsArticle is the right type for a press release, with an Organization node for the publisher and the company. Include the headline, both dates, the canonical URL in mainEntityOfPage, the image and the author. This tool produces all of it.

      

      

        Does schema markup make my release rank better?
        
No. Structured data helps machines understand what a page is and may make it eligible for enhanced presentation, but it is not a ranking factor and it does not guarantee any search feature. It has to match what is actually visible on the page.

      

      

        What is mainEntityOfPage and why does it matter here?
        
It declares which URL is the canonical home of this content. For a syndicated press release that is the single most important field, because it tells search engines which copy is the original when the same text appears in several places. Getting it wrong means reprints compete with the page you control.

      

      

        Do I need dateModified?
        
Set it equal to datePublished at first, then update it whenever you correct the release. News surfaces read it as a freshness signal, and it is also how a correction becomes visible to automated systems rather than only to humans.
