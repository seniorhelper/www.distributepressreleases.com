About these tools

Are these press release tools really free?

Yes. No account, no email capture, no trial. They run as code in your browser, so there is no cost to us in serving them and no reason to gate them.

Do you store what I paste into them?

No, and we could not if we wanted to. Every tool is client-side JavaScript with no network request. Your text never leaves your device.

Can I use the output commercially?

Yes. Anything these tools produce — a release draft, schema markup, a headline — is yours to use however you like, with no attribution required.

Which tool should I start with?

If you are not sure you have news, start with the newsworthiness check. If you have a draft, start with the grader. If you are starting from nothing, start with the template builder.
