Filtered feeds

One firehose is useless to a specialist publication. These carry only the slice you asked for, and new ones appear automatically as releases are published in new sectors and regions.

By industry

/feeds/industry/<slug>.xml

For example /feeds/industry/home-services.xml. Browse the directory to see which sectors currently have releases.

By region

/feeds/region/<slug>.xml

For example /feeds/region/colorado.xml. Regions are created as releases are published from them.

Republishing

Take any of it. We ask one thing: attribute to the canonical release URL rather than to a syndicated copy, so the original keeps the credit. Every item carries a paid-placement label, and we would ask you to keep it.

If you would rather not run a feed importer, the embed renders a filtered list client-side with one script tag. It passes no ranking credit in either direction, so it is not a link scheme for either of us.
