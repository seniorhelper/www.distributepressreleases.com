AI disclosure

How we use automated tools

Written out in full, because you should not have to guess which parts of a service involve a machine.

Audio narration

Narration on every release and every podcast episode is synthetic speech generated by text-to-speech software, unless you supply your own recording. Every episode carries this disclosure in the episode description and spoken at the end. If you would rather use a human voice, send a recording and we will publish it instead at no extra cost.

Writing and editing

We use automated tools to assist in drafting and editing. Every release is reviewed by a person before it reaches you, and nothing publishes until you have approved it. Facts come from what you supply. We do not use generative tools to invent details, figures, quotes or context, and any quote in your release is one you provided or approved.

Publishing and distribution

Publishing, feed generation, structured data, search engine notification, social posting and audio encoding all run as automated jobs. This is ordinary software automation rather than generative AI, and it is the reason fifteen deliverables fit inside a $99 price.

The assistant on this site

Wire, the chat assistant, is a rule-based script with a fixed set of answers. It is not a language model, it does not generate text, and it has no access to your data. When it does not have an answer it says so and points you to a person rather than improvising one.

The free tools

Every tool on this site is deterministic code running in your browser. No model, no API call, no data transmitted. The same input always produces the same output, and you can read exactly how each one works by viewing the page source.

What we do not do

  • We do not generate fake quotes, statistics, testimonials or endorsements.
  • We do not publish machine-written content without human review and customer approval.
  • We do not clone anyone's voice.
  • We do not present synthetic narration as a human reading.
